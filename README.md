# Palette Atelier

A standalone Design System Workbench — build, preview, validate, compare, document, and export design systems in one place.

Originally started inside the OOTD (Outfit Of The Day) app project, Palette Atelier has since grown into an independent tool that isn't tied to any single app.

## Goals
- Palette exploration
- Component preview
- Accessibility-first
