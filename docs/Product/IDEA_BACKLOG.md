# IDEA_BACKLOG

> Future ideas and long-term product evolution.
>
> This document collects ideas that are intentionally postponed.
> Moving an idea here does **not** mean rejecting it.
> It simply means "not now."

---

# Guiding Principle

A good idea is not automatically the next feature.

Palette Atelier follows **MVP First**.

Ideas should be implemented only when they improve the product without disrupting its current stage.

# Design Rule Engine

Status

🌿 Planned

Priority

⭐⭐⭐⭐⭐

## Goal

Evaluate design systems using deterministic rules instead of subjective opinions.

## Examples

- Contrast
- Naming
- Typography
- Spacing
- Radius
- Elevation
- Component Consistency

## Why

Rules are reproducible.

AI opinions are not.

# Ideas Rejected (for now)

The following ideas intentionally remain outside the product scope.

- Full UI Design Tool
- Figma Replacement
- Image Editor
- Graphic Design Software

Palette Atelier focuses on **Design Systems**, not general UI creation.

---

# Backlog Policy

An idea enters this document when:

- It is valuable.
- It is not required for the current phase.

An idea leaves this document when:

- Product design is complete.
- It enters the official roadmap.

---

# Product Vision Reminder

Palette Atelier is not a palette generator.

It is becoming a **Design System Workbench**.

Every future idea should reinforce that identity.
