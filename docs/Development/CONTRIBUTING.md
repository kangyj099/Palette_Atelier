# CONTRIBUTING

Thank you for contributing to Palette Atelier!

---

# Before Contributing

Please read

- Core/README.md
- Core/PROJECT_RULES.md
- Core/ARCHITECTURE.md
- Core/ENGINEERING_GUIDE.md

---

# Workflow

1. Create a branch
2. Implement one logical change
3. Update documentation
4. Submit a Pull Request

---

# Coding Principles

- No hardcoded values
- Respect architecture
- Use semantic tokens
- Keep modules focused

---

# Commit Messages

Follow Conventional Commits.

Examples

feat(button): add loading state

fix(layout): improve responsive grid

docs(vision): update mission statement

---

# Pull Requests

A PR should contain

- One logical purpose
- Clear description
- Screenshots if UI changed

---

# Reviews

Reviews should focus on

- Correctness
- Maintainability
- Accessibility

Not personal preference.

---

# Thank You

Palette Atelier is built through thoughtful engineering and clear design principles.

Thank you for helping improve it.
